# Credit Card Form Demo

高機能なクレジットカード入力フォームのデモアプリケーション。リアルタイムバリデーション、自動フォーマット、ブランド検出、Luhnアルゴリズム検証などの機能を実装。

## 主な機能

### 🎯 リアルタイムバリデーション

- 入力中にエラーメッセージがリアルタイムで更新される
- フォーカス離脱時の詳細バリデーション
- TanStackFormのバイパスによる高速レスポンス

### 💳 クレジットカード番号フィールド

- **自動フォーマット**: ブランド別の区切り文字挿入 (例: Visa 4444-4444-4444-4444)
- **ブランド検出**: Visa, MasterCard, JCB, American Express, Diners Club対応
- **Luhnアルゴリズム検証**: 数学的な有効性チェック
- **カーソル位置調整**: フォーマット時の自然な入力体験

### 👤 カード名義人フィールド

- **国際的な名前対応**: あらゆる言語・文字体系の名前を入力可能
- **最小限のバリデーション**: 必須入力のみチェック
- **英語キーボード優先**: lang="en"でモバイル体験向上
- **入力フリーダム**: 特殊文字やハイフンなど名前の自然な表記に対応

### 📅 有効期限フィールド

- **MM/YY自動フォーマット**: スラッシュの自動挿入
- **スマート補完**: 2→02/ のような月の自動補完
- **削除時の自動調整**: バックスペース時のスラッシュ除去
- **期限バリデーション**: 過去日付の検証

### 🔒 セキュリティコードフィールド

- **マスク入力**: パスワードタイプで秘匿性確保
- **数字のみ**: inputmode="numeric"でモバイル最適化
- **長さバリデーション**: 3-4桁の動的チェック
- **ブランド連動**: 将来的なAmex 4桁対応準備
